Espace {{ role }}

{% if role == 'Élève' %}

Bienvenue dans ton espace de révision ! Ici, tu peux accéder aux cours et aux quiz préparés par tes professeurs pour la ou les classes auxquelles tu es inscrit.

N'hésite pas à consulter tes résultats et ta progression pour voir tes points forts et les notions à retravailler. Si ton professeur t'a laissé une suggestion personnalisée, tu la retrouveras sur ton tableau de bord.

{% elif role == 'Enseignant' %}

Votre rôle est de guider vos élèves tout au long de l'année. Depuis cet espace, vous gérez vos classes et suivez les résultats détaillés de chaque élève.

Vous disposez également d'une grande liberté pédagogique : vous pouvez sélectionner, réorganiser ou créer des activités locales pour vos séances. Toutes les ressources partagées par vos collègues sont également accessibles via la Banque des activités.

{% elif role == 'Concepteur' %}

Vous êtes l'auteur des contenus pédagogiques. Votre atelier vous permet de créer des séquences, de définir les intentions (le plan préalable) et de rédiger le contenu final.

Une fois votre travail prêt, vous le soumettez aux Référents pour validation. Vous pouvez également retrouver et approuver les activités locales proposées par les enseignants pour les intégrer au programme officiel.

{% elif role == 'Référent' %}

Vous êtes le garant de la qualité pédagogique de la plateforme. Votre mission est de relire les intentions et les contenus rédigés par les Concepteurs.

Vous pouvez les valider pour confirmer leur pertinence, ou les rejeter en laissant un commentaire constructif pour guider les auteurs. Vous avez également la possibilité de donner un second avis sur les séquences demandées par le Superviseur.

{% elif role == 'Superviseur' %}

Vous êtes le garant du bon déroulement du cycle de vie des séquences. Votre rôle consiste à suivre l'avancement des projets de rédaction et à publier les séquences une fois qu'elles sont validées par les Référents.

Vous pouvez également demander un second avis ou dépublier une séquence si nécessaire, tout en gardant un œil sur les statistiques globales d'utilisation.

{% elif role == 'Administrateur' %}

Vous avez la charge technique de la plateforme. Vous gérez les comptes utilisateurs, l'attribution des rôles, ainsi que les paramètres globaux de l'application.

Vous pouvez intervenir directement via l'interface d'administration Django pour corriger des erreurs ou configurer de nouvelles matières. Votre but est de garantir la stabilité et la sécurité du système pour tous les autres utilisateurs.

{% endif %}
