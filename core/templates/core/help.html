{% if role == 'Élève' %}

Comment utiliser ton espace de révision ?

1. Rejoindre une classe

Si tu n'as pas encore accès aux cours, demande un code d'invitation à ton professeur. Sur ton tableau de bord, clique sur "Rejoindre une classe" et saisis ce code.

2. Suivre un cours ou faire un quiz

Sur ta page d'accueil, clique sur une matière pour voir les chapitres. Ensuite, navigue de séquence en séance pour trouver les activités. Une activité avec l'icône Quiz se fait directement en ligne : tu réponds aux questions une par une et tu obtiens ton score à la fin.

3. Consulter tes résultats et ta progression

Dans le menu, la section "Ma progression" te permet de voir tes moyennes par matière et les badges que tu as gagnés. Plus tu réussis tes quiz, plus tu progresses !

{% elif role == 'Enseignant' %}

Guide de l'Enseignant

Votre espace vous permet de gérer vos classes et d'adapter les contenus du programme.

Gérer vos classes

Créez une classe depuis votre tableau de bord. Un code d'invitation unique sera généré : distribuez-le à vos élèves pour qu'ils puissent vous rejoindre. Vous pouvez ensuite associer des séquences du programme à cette classe.

Suivre les résultats

Cliquez sur une classe puis sur un élève pour voir le détail de ses résultats, ses moyennes par matière et les suggestions que vous lui avez envoyées.

Liberté pédagogique

Lors de la préparation d'une séance, vous pouvez activer ou désactiver les activités proposées par les Concepteurs, les réorganiser, ou même créer vos propres activités locales. Si vous créez une activité qui vous semble pertinente pour tous, vous pouvez la proposer aux Concepteurs via le bouton "Proposer".

{% elif role == 'Concepteur' %}

Guide du Concepteur

Votre atelier est dédié à la création de contenus pédagogiques.

Créer une séquence

Utilisez le bouton "Nouvelle séquence" pour créer un brouillon dans un chapitre. Remplissez ensuite les objectifs et le plan prévisionnel des séances. Une fois prêt, soumettez l'intention au Référent.

Remplir le contenu

Lorsque l'intention est validée, vous pouvez ajouter les vraies séances, les activités (cours, TP, quiz) et soumettre le contenu final au Référent.

Gérer les propositions

Si des enseignants proposent des activités locales, vous les retrouverez dans l'onglet "Propositions". Vous pouvez les accepter pour les intégrer au programme global.

{% elif role == 'Référent' %}

Guide du Référent

Votre rôle est de valider la qualité du travail des Concepteurs.

Valider les intentions

Dans votre file d'attente, les séquences "En attente" sont des intentions. Lisez le plan prévisionnel et validez-le (ou rejetez-le avec un commentaire) pour permettre au Concepteur de commencer la rédaction.

Valider les contenus

Une fois le contenu rédigé, il apparaît dans votre file d'attente. Lisez attentivement les activités et les quiz. Si tout est bon, validez-le pour qu'il puisse être publié par le Superviseur.

Second avis

Si le Superviseur vous demande un second avis sur une séquence, vous la retrouverez dans votre onglet "Second avis". Vous pourrez confirmer ou infirmer l'avis du premier référent.

{% elif role == 'Superviseur' %}

Guide du Superviseur

Vous gérez la publication finale et le suivi global des séquences.

Publier les séquences

Lorsqu'un Référent a validé un contenu, la séquence apparaît dans "À publier". Vous pouvez la lire une dernière fois, puis cliquer sur "Publier" pour la rendre accessible aux enseignants et aux élèves.

Demander un second avis

Si vous avez un doute sur la validation d'un contenu, vous pouvez demander l'avis d'un autre Référent. La séquence sera suspendue jusqu'à la réception de ce second avis.

Suivi et dépublication

La page "Suivi des apprentissages" vous donne des statistiques d'utilisation. Si une séquence pose problème, vous pouvez la dépublier à tout moment depuis l'onglet "Publiées".

{% elif role == 'Administrateur' %}

Guide de l'Administrateur

Vous êtes le garant du bon fonctionnement technique de la plateforme.

Interface d'administration

Utilisez le bouton "Admin" sur votre tableau de bord pour accéder à l'interface Django Admin. Vous pouvez y gérer les utilisateurs, les groupes (rôles) et les matières.

Maintenance

C'est également depuis l'admin que vous pouvez intervenir en cas d'erreur de contenu, ou pour vérifier que les séquences sont bien liées aux bonnes classes.
